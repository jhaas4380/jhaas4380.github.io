Privacy policy

JARVIS · last updated 17 November 2026

Who uses JARVIS

JARVIS is a personal assistant that runs on its owner's own Windows PC. It has a single user, its owner, and is not offered to anyone else.

What Google data it accesses

Only after the owner signs in and grants access, JARVIS uses these Google Calendar permissions:

  • See events on all your calendars, to answer questions about the schedule and find clashes.
  • Create, change and delete events on calendars you own. Every such change is prepared as a draft and runs only after the owner approves that exact change.
  • See the list of your calendars, to know which calendars exist.

JARVIS does not access email, contacts, files or any other Google data.

How the data is used

  • Calendar details are used only to answer the owner's own requests and to carry out changes the owner approves.
  • To answer a request, the relevant calendar details are sent to Anthropic's Claude API, which processes them and returns an answer. Under Anthropic's commercial terms, API data is not used to train its models.
  • Calendar data is never sold, never used for advertising, and never shared with anyone else.

Where data is stored

  • The Google sign-in is stored in Windows Credential Manager on the owner's PC, encrypted with their Windows login.
  • Conversations and an activity log are stored in a database on the owner's PC. Nothing is stored on any server run by JARVIS; there is none.

Removing access

The owner can disconnect JARVIS at any time with jarvis disconnect google-calendar, or remove its access at myaccount.google.com/permissions. Memories and past conversations kept on the PC can be viewed and deleted from the JARVIS app.

Google API Services User Data Policy

JARVIS's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
